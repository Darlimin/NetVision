# История изменений

## [0.10.7]

- Добавлен раздел «Системная сеть» / System Network: фоновый снимок маршрута ядра через GetBestRoute и IP Helper API, режимы прямого подключения, VPN и раздельного маршрута, системный прокси WinINET/WinHTTP/PAC с маскировкой учётных данных и владельцем локального порта, DNS/DoH/NRPT, сравнение внешних выходов и распределение соединений с копированием локализованной сводки.
- Состояние Wi-Fi читается через Windows Native Wifi API (`wlanapi.dll`); при недоступности API сохраняется fallback на `netsh wlan`.

## [0.10.6]

- IPv4-маршруты читаются через Windows IP Helper API с явными сигнатурами и fallback на `route print`; в локальном замере нативный путь был примерно в 15 раз быстрее.
- Высота строк и ширина полей адаптированы к шрифту и масштабированию Windows; таблица TLS-сертификатов поддерживает перенос текста.
- В матрице соединений добавлено контекстное меню для удалённого endpoint: копирование, переход к MTR и синхронизированная подстановка в TCP/TLS, включая IPv6.
- Очистка Qt-виджетов и очереди `DeferredDelete` в UI-тестах сокращает время полного прогона.

## [0.10.5]

- Ускорена фоновая проверка сетевой идентичности DNS, исключены параллельные запросы и сохранён публичный IP при временном сбое.
- Отложено обновление скрытых таблиц и графика MTR; после восстановления окна данные обновляются с повторным использованием ячеек журнала.
- Добавлена запись ошибок фоновых проверок в файл с ограничением повторов и ротацией.
- Добавлены контекстные действия копирования и перехода к MTR для таблиц журнала, UDP и MTR.
- Системный заголовок Windows следует светлой или тёмной теме; улучшены навигация, справка и таблицы TCP/TLS.
- Исправлены склонение числа узлов трассировки и форматирование endpoints NAT в журнале.

## 0.10.4

- Отложен рендер скрытых таблиц журнала и UDP-событий; сбор и экспорт продолжаются в фоне.
- Таблица непрерывного MTR переиспользует ячейки и обновляется после показа.
- Таймеры анимации графика и схемы останавливаются в простое и на скрытых вкладках.
- При старте журнал читается с конца блоками; повреждённые и аномально длинные строки пропускаются.
- Из пользовательской сборки исключены отладочные файлы QtWebEngine и Rust PDB.
- Устранено наложение таблицы интерфейсов на вкладки журнала и UDP.

## 0.10.3

- Расширена справка: разбор маршрутов, состояния сокетов, FAQ о правах и приватности.
- Добавлены встроенное руководство пользователя и словарь сетевых терминов на русском и английском языках.
- Упрощена шапка навигации; улучшены светлая тема, скроллбары и читаемость таблиц.

## 0.10.2

- Уточнена компоновка обзора, график задержки, прозрачные чекбоксы и размеры таблиц/сводки.
- Исправлены переключение профилей и владение постоянными элементами меню аномалий.

## 0.10.1

- Исправлены UDP-проверки DNS и STUN, обновление публичного IP при смене сети и обработка TLS для IP-адресов.
- Улучшены управление потоками, читаемость сетевых показателей, подсказки и выбор соединений.

## 0.10.0

- Приложение перешло на Dashboard V2: рабочие области, контроллеры и события разделены по модулям. `WorkerRegistry` удерживает фоновые задачи и управляет жизненным циклом потоков Qt.
- Добавлен нативный Rust-бэкенд `netvision_rs` для разбора результатов ping и трассировки; при недоступности расширения используется Python-реализация.
- Исправлена сборка PyInstaller для окружений, которым нужен файл SSL-политики `codex-rejected-cas.pem`: устранена ошибка `[Errno 2]` при создании TLS-контекста, восстановлены TLS-аудит и GeoIP.
- Исправлен конфликт `icuuc.dll` из Poppler при упаковке: посторонняя DLL исключается из поиска зависимостей PyInstaller, благодаря чему QtCore загружается корректно.
- Добавлен оконный релиз Windows с ресурсами интерфейса, локализациями и нативным расширением Rust.
