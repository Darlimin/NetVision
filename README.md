# NetVision

NetVision — приложение для диагностики сетевого соединения в Windows. Dashboard V2 показывает задержку, потери и джиттер, проверяет DNS, TCP и TLS, помогает исследовать маршруты, NAT, MTU и качество связи под нагрузкой. Доступны мониторинг сетевых процессов и сокетов, журнал, встроенная справка и экспорт отчётов.

В версии 0.10.7 добавлен раздел «Системная сеть» для исследования фактического пути трафика и нативное чтение состояния Wi-Fi в Windows. Необязательный Rust-модуль `netvision_rs` ускоряет разбор вывода ping и трассировки; при его недоступности используется Python-реализация. Фоновые задачи управляются через `WorkerRegistry`.

## Готовая сборка для Windows

Скачайте ZIP-архив для Windows из раздела Releases, распакуйте его целиком и запустите `NetVision.exe`. Python и Rust для запуска готовой сборки не требуются.

## Запуск из исходного кода

Требуются Windows 10 или Windows 11, Python 3.11 или новее, PowerShell и доступ к интернету для внешних проверок. В PowerShell из корня проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m netvision
```

Для сборки необязательного расширения Rust установите Rust и Maturin и выполните `maturin develop` из каталога `netvision_rs`. Без расширения доступны резервные Python-парсеры.

## Возможности и ограничения

- Проверка выбранной цели: DNS, ping, TCP/TLS, потери, джиттер и трассировка.
- Сетевые интерфейсы и маршруты, сведения GeoIP/ASN для публичных адресов, сравнение маршрутов и обнаружение VPN.
- «Системная сеть» / System Network: маршрут, прокси, DNS, внешний выход и распределение соединений по каналам.
- Анализ процессов и TCP/UDP-сокетов, журнал сессии, проверка NAT/STUN, MTU и Bufferbloat.
- Отчёт и пакет для техподдержки могут содержать сетевые адреса, имена процессов и адаптеров. Перед публикацией проверьте их содержимое; в пакете доступно скрытие личных данных.
- Некоторые действия изменения сетевых настроек требуют прав администратора Windows. Внешние проверки зависят от сети и могут ограничиваться VPN, брандмауэром или удалённой стороной.

Описание изменений версий — в [CHANGELOG.md](CHANGELOG.md). Условия использования и уведомления приведены в `EULA.txt` и `NOTICE.txt`.
